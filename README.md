# カリブー 公式サイト

- `site/` … 公開するファイル一式（このフォルダの中身をそのままアップロードすれば動く。ビルド不要）
  - `index.html` トップ／`shoes.html` シューズ実測マップ／`videos.html` 動画一覧／`about.html` プロフィール
  - `data/data.js` 動画一覧と実測データ（`work/build.py` が自動で作る。手で直さない）
  - `img/shoes/` 靴の写真（自分で撮ったもの）
- `work/` … データを作る道具
  - `update.sh` … YouTubeの動画一覧を取り直して `data.js` を作り直す
  - `build.py` … **実測データ（20足）はこのファイルの `S = [...]` に書いてある**。靴を足すときはここに1行足し、写真を `site/img/shoes/c_<記号>.jpg`（横800px・16:9）で置く
  - `sync.sh` … Claudeのプレビュー用

## 新しい動画を反映する
```
sh work/update.sh
```
そのあと `site/` を公開先にアップロードし直す。

## 靴を足すとき
1. `work/build.py` の `S` に1行足す（重さ・かたさ・反発・用途の記号・レビュー動画のID）
2. 写真を `site/img/shoes/c_<記号>.jpg` に置く
3. `sh work/update.sh`

## 目標タイムの分類（サブ3〜完走）
- `work/build.py` がタイトルから自動で付ける（「サブ5〜サブ3」のように幅があれば間も埋める）。
- タイトルから決まらない動画（シューズのレビューなど）は、同じファイルの `GOAL_FIX` に動画IDと目標を手で書く。
- 新しいシューズのレビューを出したら、`GOAL_FIX` に1行足してから `sh work/update.sh`。

## 文章の改行
- `site/js/app.js` が、日本語を言葉の切れ目だけで折り返すようにしている。
- 途中で切れてほしくない言葉があれば、同じファイルの `KEEP` の一覧に足す。

## 載せる動画

日本語チャンネルの横動画だけを載せます。ショートと英語チャンネルの動画は載せません（英語チャンネルは、SNS欄の下に一行で紹介するだけ）。

## 共有用の画像（OGP）

キャッチコピーを変えたら `work/ogp.py` の文字を直して `python3 work/ogp.py`。Chrome を使って `site/img/ogp.png` を作ります。

## トップの背景

シューズ写真と顔写真を並べた画像です。靴を足したら `work/hero_bg.py` の並び順に追加して `python3 work/hero_bg.py`。
